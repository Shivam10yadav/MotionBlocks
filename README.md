# MotionBlocks

MotionBlocks is a modern React UI component library featuring beautifully crafted, reusable, and animated components built with React, Tailwind CSS, and Framer Motion.

Browse components, preview them live, and copy the code directly into your projects—no npm package required.

## ✨ Features

- Beautiful animated UI components
- Copy & paste ready code
- Built with React + Tailwind CSS
- Fully customizable
- Responsive by default
- Live component previews
- Organized by categories

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router

## 📂 Categories

- Buttons
- Cards
- Hero Sections
- Backgrounds
- Loaders
- Forms
- Navigation
- Text Effects

## 🚀 Getting Started

```bash
git clone <repository-url>

cd motionblocks

npm install

npm run dev
```
